# std-metadata — метаданные и имена

Источник ИТС (сессия): [#std550 Имена объектов метаданных](https://its.1c.ru/db/v8std/content/550/hdoc)  
Раздел: [Организация работы конфигурации](https://its.1c.ru/db/v8std/browse/13/-1/1/2).  
Общие модули подробно: `std-code-style` (#std469).

## Общий принцип (#std550)

- Имя отражает назначение; без мусорных слов (`Справочник…`, `Документ…`, `Форма…`, `Макет…`, `Отчет…`, `Обработка…`, `Константа…` и т.п.), если без них смысл тот же.
- См. также ограничения на переименование объектов метаданных (раздел ИТС).

## Краткая шпаргалка по типам

| Объект | Правило имени | Примеры |
|--------|---------------|---------|
| Подсистемы | общие правила | `Финансы`, `Маркетинг` |
| Общие модули | #std469 / постфиксы | `…ВызовСервера`, `…Клиент` |
| Параметры сеанса | общие правила | `ТекущийПользователь` |
| Роли | должность **или** действие | `Бухгалтер` / `ДобавлениеИзменениеНСИ` |
| Планы обмена | РИБ — суть отбора; между конф. — `ОбменИсточникПриемник` (+ версии) | `ПоОрганизациям`, `ОбменУТБухгалтерия` |
| Критерии отбора | мн. число, список объектов | `СвязанныеДокументы` |
| Подписки | глагол неопред. формы, суть действия | `ПроверитьИзменениеРеквизитовОбъекта` (не `…ПередЗаписью`) |
| Рег. задания | ед. число, существительное | `УстановкаПериодаРассчитанныхИтогов` |
| Функц. опции | описание включаемой функции | `ИспользоватьБизнесПроцессыИЗадачи` |
| Опред. типы | ед. число, назначение; не `Строка`/`Тип…` | `АртикулНоменклатуры` |
| Общие формы/команды | сущ. / список или глагол | `ПараметрыПроксиСервера`, `УстановитьРасширение…` |
| Web-сервисы | **англ.** существительные | `Files`, `GetCurrencyRate` |
| Константы | объект хранения; Булево — глагол | `ТипХраненияФайлов`, `ВыполнятьПроверкуЭЦПНаСервере` |
| Справочники | **мн.** число | `Валюты`, `Пользователи` |
| Документы | **ед.** число; суть процесса (не «Акт…» без нужды) | `СверкаВзаиморасчетов` |
| Журналы | мн. число | `СкладскиеДокументы` |
| Перечисления | мн. число | `ВариантыВажностиЗадачи` |
| Отчёты/обработки | существительное | `СписокЗависшихЗадач` |
| Регистры св./нак. | мн. число, список записей | `ДвиженияДенежныхСредств` |
| Бизнес-процессы / задачи | ед. число | `Согласование`, `ЗадачаИсполнителя` |

Документ: имя = процесс в системе; если документ только ради печатной формы — допустимо имя от печатной формы (`ТоварноТранспортнаяНакладная`).

Отчёты: представление варианта лаконично и уникально (`ВаловаяПрибыльПоЗаказам`, не «Основной»); совпадает с заголовком печати при наличии.

Обработка, открываемая из навигации: имя = имя команды открытия.

## Организация

- Новый функционал — в понятные **подсистемы**.
- Права на новые объекты — сразу (`std-access-rights`).
- Переименование существующих — с учётом обменов/внешних интеграций.

## Чеклист

- [ ] Число/часть речи по типу объекта (#std550)
- [ ] Нет мусорных префиксов `Справочник`/`Документ`/`Форма`…
- [ ] Роль: должность или действие — осознанно
- [ ] План обмена / Web-сервис названы по схеме
- [ ] Общие модули — `std-code-style`
