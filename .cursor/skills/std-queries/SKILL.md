# std-queries — работа с запросами

Источник ИТС (сессия): [#std437 Оформление текстов запросов](https://its.1c.ru/db/v8std/content/437/hdoc)  
Раздел: [Работа с запросами](https://its.1c.ru/db/v8std/browse/13/-1/26/27).

Если вопрос про скорость/индексы/ВТ — дополнительно грузи `std-query-optimization`.  
Шаблоны/сборка сложных запросов — [docs/query-writing.md](docs/query-writing.md) (адапт. ai_rules_1c).  
Runtime COM-проверка синтаксиса — skill `1c-query-validate` (opt-in, только оркестратор).

## #std437 — оформление (must)

1. Ключевые слова языка запросов — **ЗАГЛАВНЫМИ**.
2. Явно назначай псевдонимы полям (`… КАК Имя`): код, читающий выборку, не ломается при переименовании реквизита.
3. Для разыменований (`Касса.Валюта.Наименование`) автопсевдоним будет `ВалютаНаименование`, не `Наименование` — учитывай.
4. Перед псевдонимом поля источника обязательно `КАК`.
5. Не пиши запрос в одну строку — структурируй (`ВЫБРАТЬ` / `ИЗ` / …).
6. В сложных запросах (вложенные, объединения, соединения) — комментарии; помни: **конструктор запросов удаляет комментарии** без предупреждения.
7. У объекта `Запрос` — комментарий о цели (какие данные / зачем).
8. При программной сборке текста:
   - комментируй этапы сборки;
   - каждая часть должна открываться в **конструкторе запросов**.

### Программная модификация текста

- Подстановку имени поля/таблицы делай через плейсхолдер + `СтрЗаменить`, а не склейку посередине строки поля.
- Для опционального `ПОМЕСТИТЬ`: держи `ПОМЕСТИТЬ` в тексте и удаляй при ненужности; не «раскомментируй» через замену `// ПОМЕСТИТЬ`.
- Пакет запросов: сначала целый кусок без завершающего `;`, затем добавляй разделитель `;` + следующий кусок (или `СтрСоединить` массива).

## Прочие темы раздела ИТС (при касании)

Пустой результат, `ПОЛНОЕ ВНЕШНЕЕ СОЕДИНЕНИЕ`, `ОБЪЕДИНИТЬ` vs `ОБЪЕДИНИТЬ ВСЕ`, упорядочивание, `ПОДОБНО`, псевдонимы источников, подсчёт количества — см. статьи того же раздела на ИТС.
