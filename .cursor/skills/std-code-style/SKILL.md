## #std469 — общие модули

Один модуль — процедуры/функции одного признака (подсистема или сходное назначение).

| Тип | Пример имени | Вызов сервера | Назначение |
|-----|--------------|---------------|------------|
| Серверный | `ОбщегоНазначения` / `…Сервер` | нет | Внутренняя серверная логика; доступны мутабельные типы |
| Серверный для клиента | `…ВызовСервера` | да | Клиентский API сервера; **без** мутабельных параметров |
| Клиентский | `…Клиент` | — | Только клиентская логика |
| Клиент-серверный | `…КлиентСервер` | нет | Одинаковый код на клиенте и сервере |

Серверный (п.2.1): признаки `Сервер` (без «Вызов сервера») + `Клиент (обычное приложение)` + `Внешнее соединение` — чтобы работали подписки/передача `СправочникОбъект` и т.п.

**Must not в `…КлиентСервер`:** ветвить сервер/клиент через `#Если Сервер` / `#Если Клиент`. Разноси разное по модулям `…Сервер` / `…Клиент` (#std439).

Постфиксы: `Глобальный`, `ПолныеПрава`, `ПовтИсп` / `КлиентПовтИсп`, `Переопределяемый` / `КлиентПереопределяемый`, `Локализация` / `КлиентЛокализация`.

Имена — по подсистеме/механизму; избегай слов `Процедуры`, `Функции`, `Обработчики`, `Модуль`, `Функциональность` без нужды.

## #std679 — «Вызов сервера»

1. Не ставь «Вызов сервера» всем серверным модулям по умолчанию.
2. В модулях с флагом — только то, что реально зовут с клиента и что безопасно для прав пользователя (не тащи сырые/промежуточные данные).
3. Особо осторожно с привилегированным режимом / модулями `ПолныеПрава`.
4. Работа с экземплярами объектов (`СправочникОбъект`, `ДокументОбъект`, …) — на сервере; не создавай/не получай их в клиентских общих модулях и в обычных формах под УА.
5. Если толстый клиент (УА, клиент-сервер) не нужен — сними соответствующий флажок конфигурации (меньше ложных ошибок проверки).

## Структура модуля (#std455)

Оформляй разделами-областями; пустые области не оставляй.

- Общий модуль: `ПрограммныйИнтерфейс` → `СлужебныйПрограммныйИнтерфейс` → `СлужебныеПроцедурыИФункции`
- Объект/менеджер: переменные → API → обработчики событий → служебный API → служебные → инициализация
- Форма: события формы → шапка → таблицы → команды → служебные

Обработчики формы не вызывай из кода напрямую — выноси общую логику.

## Чеклист

- [ ] Тип/постфикс общего модуля по #std469
- [ ] «Вызов сервера» только для клиентского API (#std679)
- [ ] Нет мутабельных типов в API с клиента
- [ ] Области по шаблону (#std455)
- [ ] Нет `#Если Сервер` внутри `КлиентСервер`
