# std-data-exchange — обмен данными

Источник ИТС (сессия): [#std773 ОбменДанными.Загрузка](https://its.1c.ru/db/v8std/content/773/hdoc)  
Раздел: [Реализация обмена данными](https://its.1c.ru/db/v8std/browse/13/-1/38).

## #std773 — must в обработчиках

В `ПередЗаписью`, `ПриЗаписи`, `ПередУдалением` **все действия** — только после:

```bsl
Если ОбменДанными.Загрузка Тогда
    Возврат;
КонецЕсли;
```

Иначе при обмене бизнес-логика выполнится повторно; объект должен грузиться «как есть» — без проверок/искажений/лишних действий.

То же для любых механизмов загрузки «как есть»:

```bsl
Объект.ОбменДанными.Загрузка = Истина;
Объект.Записать();
```

(ориентир стандарта: как будто текста обработчика нет).

Требование распространяется и на **подписки** на эти события.

## Исключения (#std773)

1. Обмен, который при загрузке регистрирует данные к выгрузке на другие узлы плана обмена.
2. БСП «Обмен данными» — при необходимости отключить регистрацию:

```bsl
Объект.ОбменДанными.Загрузка = Истина;
Объект.ДополнительныеСвойства.Вставить("ОтключитьМеханизмРегистрацииОбъектов");
Объект.Записать();
```

3. Другие исключения — только с комментарием причины в коде.

Кто выставил `Загрузка = Истина`, тот отвечает за целостность.  
При конвертации / **EnterpriseData** — дозаполнение в экспортных процедурах объекта, вызываемых **до** записи в режиме обмена.
