## #std658 — эффективные условия (must)

Цель: не допускать существенного роста времени при росте объёма данных.

1. Поля **основного** условия в `ГДЕ`, `ПО` и параметрах виртуальных таблиц — **проиндексированы**.
2. Основное условие уточняется дополнительным только через **`И`**.
3. Основное = сильнее всего режет выборку; доп. = любая сложность (`НЕ`, `<>`, арифметика, функции…).
4. В основном условии только операции, совместимые с индексом:
   - для всех используемых полей индекса, кроме последнего: только `=` и `И`;
   - для последнего (или единственного): `=`, `>`, `<`, `>=`, `<=`, `ПОДОБНО`, `МЕЖДУ`, `В`, `ИЛИ` (приводимое к `В`);
   - нельзя: арифметика, функции, отрицания и неравенства на полях индекса.
5. Индексация:
   - `ГДЕ` / ВТ → поля основной таблицы выборки;
   - `ПО` левого соединения → правая таблица;
   - `ПО` внутреннего → таблица с большим числом записей.
6. Желательно опираться на индексы, которые создаёт платформа автоматически.

Исключения (п.1.1): всегда < ~1000 записей или редкие запросы.

Если нельзя соблюсти (п.1.2): преобразовать условия (ПОДОБНО/МЕЖДУ), добавить вычисляемые индексируемые поля при записи, иначе пересмотреть архитектуру.

### ИЛИ / ПОДОБНО / МЕЖДУ / ВЫБОР / арифметика

- `ИЛИ` в основном условии — только на последнем поле индекса и если сводится к `В`; иначе часто `ОБЪЕДИНИТЬ ВСЕ` (если семантика та же).
- В доп. условии `ИЛИ` без ограничений.
- `ПОДСТРОКА`/`МЕСЯЦ` → по возможности `ПОДОБНО` / `МЕЖДУ` на индексируемом поле; литерал `ПОДОБНО` не должен начинаться с `_` или `%`.
- `ВЫБОР` и арифметика над полями — только в **дополнительном** условии.

### RLS (п.7)

Несколько ролей с **разным** RLS на одно право одного объекта у одного пользователя → в СУБД `ИЛИ` → медленно и лишние блокировки.  
Делай: одна роль на право объекта **или** одинаковые условия RLS.

## Чеклист

- [ ] Основное условие индексируемо (#std658)
- [ ] Нет «плохого» ИЛИ / функций в основном условии
- [ ] Параметры виртуальных таблиц заданы
- [ ] Нет запроса в цикле
- [ ] RLS ролей не плодит скрытый ИЛИ
